# 미장 개장 30분 급등 상위 10종목 패턴 분석

미국 주식 1분봉으로 **매일 개장 후 30분(09:30~10:00 뉴욕시간) 상승률 상위 10종목**을 찾아
30분 동안의 움직임 패턴을 분석합니다. 가장 최근 거래일부터 **하루씩 과거로 표본을 늘려가며**
**95% 신뢰수준**을 만족하는 패턴이 안정적으로 나올 때까지 반복(백워드 회귀 테스트)합니다.

## 빠른 시작 (Windows)

1. [Python 3.10+](https://www.python.org) 설치 (설치 시 **Add python.exe to PATH** 체크)
2. 이 폴더(`us_opening_surge`)의 파일을 작업폴더(예: `바탕 화면\미주`)에 복사
3. `run.bat` 더블클릭 → 첫 실행 때 필요한 패키지가 자동으로 설치됩니다. 끝나면 보고서(`report.html`)가 자동으로 열립니다.

명령창에서 옵션을 주고 실행할 수도 있습니다:

```bat
run.bat                                   :: 야후 무료 데이터 (최근 약 20거래일)
run.bat --source alpaca --max-days 250    :: 알파카 무료 API (수년치 1분봉)
run.bat --target-rate 0.8                 :: 적중률 기준을 80%로 높임
run.bat --source synthetic                :: 인터넷 없이 가상 데이터로 동작만 확인
```

## 데이터 소스

| 소스 | 키 필요 | 1분봉 과거 범위 | 비고 |
|---|---|---|---|
| `yahoo` (기본) | 없음 | **최근 약 30일(≈20거래일)** | 바로 사용 가능. 첫 실행 때 전 종목 일봉을 받느라 수 분 걸림(이후 캐시) |
| `alpaca` | 무료 가입 후 API 키 | 수년 | 회귀를 길게 하려면 권장 |

알파카 사용법: https://alpaca.markets 무료 가입 → API Keys 발급 → 명령창에서

```bat
setx ALPACA_API_KEY "발급받은키"
setx ALPACA_SECRET_KEY "발급받은시크릿"
```

(창을 새로 연 뒤 `run.bat --source alpaca`. 무료 계정에서 SIP 오류가 나면 `--alpaca-feed iex`)

## 작동 방식

1. **종목 목록**: 나스닥트레이더 상장 목록(NASDAQ·NYSE·AMEX 등 약 6천 종목)에서 ETF·워런트·우선주 등을 제외
2. **일별 상위 10 찾기**: 30분 상승률은 항상 `당일 고가/시가 - 1` 이하라는 점을 이용해, 일봉 기준 상한이 큰 종목부터
   1분봉을 확인하다가 남은 후보의 상한이 현재 10위보다 낮아지면 멈춥니다. 전 종목 분봉을 받지 않고도 **정확한 상위 10**을 구합니다.
   (기본 필터: 주가 $1 이상, 30분 거래대금 $100만 이상. 동전주 노이즈 제거용이며 `--min-price`, `--min-dollar-volume` 으로 변경)
3. **종목별 30분 특징**: 갭, 첫 5분 수익률, 고점·저점 시각, VWAP 위 체류비율, 최대 되밀림, 거래대금 분포, 양봉비율 등
   + **형태 분류** (계단식 상승 / 초반 급등 후 유지 / 후반 급등 / V자 반등 / 급등 후 되밀림 / 변동성 상승)
   + **10:00 이후 흐름** (10:30·11:00·장마감 가격, 이후 고점 돌파 여부, 이후 최대 상승·하락폭)
4. **패턴 판정**: 약 110개 규칙을 시험합니다.
   - `형태`: 상위 종목의 30분 모양 (예: "고점이 마지막 5분에 형성")
   - `이후흐름`: 10:00 상위 10종목의 이후 움직임 (예: "10:30 가격 < 10:00 가격")
   - `조건부`: 30분 형태 → 이후 흐름 (예: "[VWAP 위 체류 80% 이상] → 11:00 가격 < 10:00 가격")
   각 규칙의 적중률에 대해 **Wilson 95% 신뢰구간**을 구하고, **하한이 목표 적중률(기본 70%) 이상 + 표본 30개 이상**이면 '확정'으로 봅니다.
   여러 규칙을 한꺼번에 시험하면 우연히 맞는 패턴이 생기므로 **Bonferroni 다중검정 보정**을 기본 적용합니다.
5. **백워드 반복**: 최근일 → 과거로 하루씩 추가. 실전 활용 패턴(이후흐름·조건부)이 **3일 연속 확정**되면 종료합니다.

### "신뢰도 95%"의 의미
기본값은 **"95% 신뢰수준에서 적중률이 최소 70% 이상임이 통계적으로 확인된 패턴"** 입니다.
"95% 확률로 맞는 패턴"을 원하면 `--target-rate 0.95` 로 실행하세요. 다만 이렇게 높은 기준을 넘는 실전 패턴은 거의 없어서
보통 최대 일수까지 회귀하고 끝납니다.

| 파일 | 내용 |
|---|---|

| `daily_summary.csv` | 날짜별 요약 (형태 분포, 이후 하락 비율 등) |
| `patterns_final.csv` / `patterns_history.csv` | 최종 패턴 통계 / 하루씩 늘릴 때마다의 통계 변화 |

받은 데이터는 `cache\` 에 저장되므로 다시 실행하면 빠릅니다.

## 주요 옵션

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--top` | 10 | 일별 상위 종목 수 |
| `--window` | 30 | 개장 후 분석 구간(분) |
| `--base` | open | `open`: 시가 대비 / `prevclose`: 전일 종가 대비(갭 포함) 상승률 |
| `--confidence` | 0.95 | 신뢰수준 |
| `--target-rate` | 0.70 | 확정에 필요한 적중률 신뢰구간 하한 |
| `--min-samples` | 30 | 패턴 판정 최소 표본 |
| `--stable-days` | 3 | 몇 번 연속 확정되면 멈출지 |
| `--max-days` | 250 | 최대 회귀 거래일 (야후는 자동으로 약 20일로 제한) |
| `--stop-on` | actionable | `any`: 형태 패턴 확정에도 종료 / `none`: 최대 일수까지 계속 |
| `--no-bonferroni` | - | 다중검정 보정 끄기 (패턴이 쉽게 나오지만 우연일 가능성 증가) |
| `--end-date` | 직전 거래일 | 가장 최근 분석일 (YYYY-MM-DD) |
| `--universe-file` | - | 직접 만든 종목 리스트 파일 |

## 주의

- `형태` 패턴은 이미 급등한 종목을 나중에 골라서 본 것이라, 선정 기준 자체의 영향을 받습니다(예: 대부분 VWAP 위에서 끝남).
  **10:00 시점에 판단할 수 있는 `이후흐름`·`조건부` 패턴**이 실제 매매에 참고할 만한 결과입니다.
- 현재 상장 종목 기준이라 그사이 상장폐지된 종목은 빠집니다. 야후 1분봉은 소형주에서 일부 분봉이 누락될 수 있습니다.
- 과거 통계는 미래 수익을 보장하지 않습니다. 수수료·슬리피지는 반영되어 있지 않습니다.
